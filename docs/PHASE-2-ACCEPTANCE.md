# Phase 2 acceptance map

This is a mapping artifact for the Phase 2 fault matrix. It ties each A/P/B/C row and each YAML case to the closest existing unit or race checks, then records the process-level evidence still required. A linked unit test is a complement to acceptance; it does not make an H or R row pass. The receipt table records the local gates; review and CI remain separate acceptance requirements.

The matrix uses **U** for deterministic unit or race checks, **H** for independently started compiled CLI/helper processes, and **R** for the isolated real pueue/pueued 4.0.4 run. `A` counts supervisor add attempts, `S` provider starts, `E` provider executable entries, `K` running-job kill requests, and `M` queued-job remove requests. A missing record is unknown, never zero. Public results remain `0` for committed success, `3` for pending/unknown/watch expiry, `4` for a recorded rejection, `1` for an operational fault (including a preserved independent winner), and `2` for configuration or usage refusal.

The links below point to the current repository files and test definitions. The H/R assertions must also retain exact per-process receipts, PIDs, argv, input/output bytes, event ordering, binding identity, and before/after record inventories. This map records observed receipts and pending gates; it does not declare final phase acceptance.

## Continuation ownership

The [application continuation regressions](../internal/app/session_continuation_test.go)
cover committed and rejected completion, already-terminal and sealed recovery,
collection, active/unknown retention, concurrent successor admission, and a
durability failure followed by release retry. The runner releases a claim only
after execution relinquishes its run lease and storage validates terminal proof.

The default H suite includes `SESSION-CHAIN`: public dispatch and runner commands
complete A, resume A as B, then resume B as C with three distinct task IDs and one
conversation ID. It checks exact briefs, raw/payload bytes, predecessor links,
B/C release evidence hashes, and unchanged results through repeated collection.
Counts are A=S=E=3 and K=M=0. The separate `SESSION-CHAIN-BASELINE` control against
the old binaries reached public C and recorded `session continuation busy`
before any C add or provider start; its receipt is `root-session-review/root-baseline-r1/`.
Concurrent admission remains covered by the unit/race test; this CLI chain is sequential.
