# Contributing

Thank you for helping improve Delegation Layer.

The detailed development setup, provider boundary, testing requirements, and
review checklist are in [docs/contributing.md](docs/contributing.md). The
repository instructions in [AGENTS.md](AGENTS.md) and the contracts under
[`agents/_data/`](agents/_data/) are also authoritative.

Before opening a change, run the checks relevant to the files you touched. The
full contributor workflow includes formatting, Go tests, race tests, skill
validation, package checks, and the repository verification targets.
